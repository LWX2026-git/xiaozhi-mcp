# 小智AI MCP 聊天室服务

## 功能
- 发送消息到聊天室
- 获取聊天室最新消息
- 获取在线人数

## 部署
1. 克隆仓库
2. 安装依赖：`npm install`
3. 设置环境变量
4. 运行：`npm start`

## 环境变量
| 变量 | 说明 |
|------|------|
| API_BASE | PHP API地址 |
| TOKEN | 用户token |
| USERNAME | 用户名 |
| PASSWORD | 密码 |
| ROOM | 房间号 |

## 小智配置
在 xiaozhi.me 控制台填入 MCP 接入点地址。
